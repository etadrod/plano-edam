# Plano EDAM

Actividad didáctica del módulo 1679 Vigilancia y Protección (Técnico en Seguridad).
El alumnado ubica medidas de seguridad físicas y electrónicas en el plano ficticio de una
Estación Desaladora de Agua de Mar (EDAM), ajusta coberturas, controla el presupuesto y
genera el informe en PDF o lo imprime desde el navegador.

Web estática sin servidor: el trabajo de cada alumno se guarda solo en su navegador.
Supuesto didáctico ficticio; no representa ninguna instalación real.
